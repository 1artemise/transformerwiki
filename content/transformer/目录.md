# Transformer 知识库目录

这套笔记的目标不是一上来背公式，而是先把 Transformer 背后的几个问题想清楚：

```text
模型怎么读文字？
模型怎么知道自己错了？
模型怎么根据错误改权重？
模型怎么在一句话里找到重点？
模型怎么从训练变成真正生成？
```

如果这些问题没有想通，直接看 `Attention(Q, K, V)`、`LayerNorm`、`Encoder-Decoder`，很容易觉得每个模块都认识，但合起来不知道在干嘛。

## 推荐阅读顺序

### 1. 先知道模型怎么学习

这一部分是最容易被教程默认跳过的，但它决定了你能不能真的理解“训练”。

- [[前置知识/神经网络|神经网络]]
- [[前置知识/损失函数|损失函数]]
- [[前置知识/梯度与反向传播|梯度与反向传播]]
- [[前置知识/梯度消失|梯度消失]]
- [[前置知识/梯度爆炸|梯度爆炸]]

你需要先建立一个直觉：**模型不是自己突然变聪明，而是每次预测错了以后，用损失函数量出错误，再用梯度告诉每个权重该往哪里改。**

### 2. 再知道文字怎么变成模型能处理的东西

Transformer 不能直接读汉字、英文单词或句子。它只能处理数字向量。

- [[前置知识/词嵌入|词嵌入]]
- [[关键模块/位置编码|位置编码]]
- [[前置知识/softmax|softmax]]

这一阶段重点不是背公式，而是理解：

```text
token 表示“输入被切成什么单位”
embedding 表示“每个 token 的语义向量”
position 表示“每个 token 在哪里”
softmax 表示“分数怎么变成概率”
```

```text

LayerNorm 负责稳定数值分布
Feed Forward 负责对每个位置的信息再加工
Encoder / Decoder 负责组织这些模块怎么读、怎么写
```

## 学到什么程度算过关

你不需要一开始就能手推所有矩阵维度，但至少要能回答这些问题：

- 为什么 Transformer 不能只用词嵌入，还要位置编码？
- 为什么 attention 里 Q 和 K 用来算分数，V 才是被汇总的信息？
- 为什么 `QK^T` 后面要除以 `sqrt(d_k)`？
- 为什么 decoder 需要 mask？
- 为什么每个子层后面都要 Add 和 LayerNorm？
- 什么是梯度？为什么梯度太大或太小都会出问题？
- 权重什么时候会继续变化，什么时候会基本不再变化？
- 训练时模型看到的东西，和推理时模型看到的东西有什么区别？

如果这些能讲清楚，再去读 `Attention Is All You Need`，会顺很多。
