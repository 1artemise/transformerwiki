# 训练排错清单

Transformer 训练出问题时，不要只盯着模型结构。

更稳的排查顺序是：

```text
数据 -> 形状 -> mask -> loss -> 梯度 -> 优化器 -> 评估
```

这篇按工程排错来写。

## 1. 先确认数据

检查输入：

```python
print(input_ids.shape)
print(input_ids.min(), input_ids.max())
print(labels.shape)
print(labels.min(), labels.max())
```

你要确认：

- token id 没有超过词表大小。
- padding id 是你预期的值。
- labels 没有全是 padding。
- batch 里不是全空文本。
- 输入和标签长度对得上。

## 2. 检查 logits 和 labels

语言模型常见输出：

```text
logits: [batch, seq_len, vocab_size]
labels: [batch, seq_len]
```

计算 loss 前通常变成：

```python
loss = criterion(
    logits.reshape(-1, logits.size(-1)),
    labels.reshape(-1),
)
```

如果 label 是下一个 token，要确认是否错开一位：

```text
输入：   A B C
标签：   B C D
```

没有错位，模型可能只是在学复制输入。

## 3. 检查 mask

mask 最容易出隐蔽 bug。

常见 mask：

```text
padding mask：挡住 padding
causal mask：挡住未来
```

要检查：

- mask 形状能否广播到 attention score。
- causal mask 方向是否反了。
- 有没有把所有位置都 mask 掉。
- padding token 是否参与 loss。

一个危险信号是：

```text
某一行 attention score 全是 -inf
```

softmax 后可能变成 NaN。

## 4. 检查 loss

训练时打印：

```python
print(loss.item())
```

如果 loss 是 NaN：

```python
print(torch.isnan(logits).any())
print(torch.isinf(logits).any())
```

如果一开始 loss 特别离谱，先检查：

- vocab size 是否对。
- labels 是否越界。
- ignore_index 是否正确。
- logits 是否已经 softmax 过。

注意：`CrossEntropyLoss` 接收的是 logits，不需要你先 softmax。

## 5. 检查梯度

```python
loss.backward()

total_norm = 0
for name, p in model.named_parameters():
    if p.grad is None:
        print("NO GRAD", name)
        continue
    norm = p.grad.norm().item()
    total_norm += norm
    if torch.isnan(p.grad).any():
        print("NAN GRAD", name)
    print(name, norm)
```

常见问题：

- 大量参数没有梯度：计算图断了，或参数被冻结。
- 梯度全是 0：loss 没连到参数，或梯度消失。
- 梯度特别大：可能梯度爆炸。
- 梯度 NaN：通常前向里已经出现不稳定。

## 6. 检查权重是否更新

```python
before = model.some_layer.weight.detach().clone()
optimizer.step()
after = model.some_layer.weight.detach().clone()
print((after - before).abs().sum())
```

如果没有变化，检查：

- 有没有 `optimizer.step()`。
- 学习率是不是 0。
- 参数有没有传给 optimizer。
- 参数 `requires_grad` 是否为 True。
- 梯度是否为 None。

## 7. 检查学习率

学习率太大：

```text
loss 上下乱跳
loss 变 NaN
梯度范数很大
```

学习率太小：

```text
loss 几乎不动
权重更新量很小
训练非常慢
```

Transformer 常用 warmup。
如果你从零训练，学习率策略比你想象中重要。

## 8. 检查 train/eval 模式

训练前：

```python
model.train()
```

推理前：

```python
model.eval()
```

区别主要影响：

- Dropout
- BatchNorm

LayerNorm 训练推理行为基本一致。

如果训练时误用了 `eval()`，Dropout 不会生效。
如果推理时误用了 `train()`，输出会有随机性。

## 9. 检查过拟合

如果训练 loss 降，验证 loss 升：

```text
模型开始背训练集
```

可以尝试：

- 减小模型。
- 加 Dropout。
- 加 weight decay。
- 增加数据。
- early stopping。
- label smoothing。

## 10. 最小化复现

复杂任务出问题时，先退回到玩具任务。

比如：

```text
输入数字序列，预测下一个数字
```

如果玩具任务能学会，说明训练链路大体是通的。
如果玩具任务都学不会，不要继续调大模型，先查代码。

## 一句话总结

训练排错不要凭感觉。

按这条线查：

```text
数据是否对
形状是否对
mask 是否对
loss 是否对
梯度是否存在
权重是否更新
验证集是否真的变好
```

每一步都能打印出来，就不会陷入“模型玄学不收敛”。
