# 最小训练实验

只看结构代码还不够。

你需要亲手跑一次很小的训练，看到：

```text
loss 怎么下降
梯度怎么出现
权重怎么变化
模型什么时候开始过拟合
```

这个实验不追求训练出一个厉害模型，只追求把训练链路跑通。

## 实验目标

做一个极小任务：

```text
输入一串数字
输出右移一位的数字
```

比如：

```text
输入：1 2 3 4
目标：2 3 4 5
```

这不是自然语言任务，但很适合检查 Transformer 的训练流程。

因为模型如果连这个都学不会，说明代码里大概率有问题。

## 为什么用玩具任务

真实翻译任务会引入太多变量：

- 分词
- 词表
- 数据清洗
- padding
- 长度分布
- 评估指标
- 训练时间

玩具任务可以先把问题缩小到：

```text
模型结构是否通
loss 是否能下降
mask 是否正确
梯度是否正常
优化器是否真的更新权重
```

## 最小数据生成

```python
import torch

def make_batch(batch_size=32, seq_len=8, vocab_size=20):
    x = torch.randint(1, vocab_size - 1, (batch_size, seq_len))
    y = (x + 1) % vocab_size
    y[y == 0] = 1
    return x, y
```

这里输入和标签形状都是：

```text
[batch, seq_len]
```

## 最小模型

可以先用 PyTorch 自带的 `nn.TransformerEncoderLayer`，不要一开始就自己写完整架构。

```python
import math
import torch
import torch.nn as nn

class TinyTransformer(nn.Module):
    def __init__(self, vocab_size=20, d_model=64, nhead=4, num_layers=2):
        super().__init__()
        self.embed = nn.Embedding(vocab_size, d_model)
        self.pos = nn.Parameter(torch.randn(1, 128, d_model) * 0.02)
        layer = nn.TransformerEncoderLayer(
            d_model=d_model,
            nhead=nhead,
            dim_feedforward=128,
            batch_first=True,
        )
        self.encoder = nn.TransformerEncoder(layer, num_layers=num_layers)
        self.out = nn.Linear(d_model, vocab_size)
        self.d_model = d_model

    def forward(self, x):
        seq_len = x.size(1)
        h = self.embed(x) * math.sqrt(self.d_model)
        h = h + self.pos[:, :seq_len]
        h = self.encoder(h)
        return self.out(h)
```

这个模型不是原始 encoder-decoder Transformer，而是一个最小 encoder 版。
目的是先看训练链路。

## 训练循环

```python
model = TinyTransformer()
criterion = nn.CrossEntropyLoss()
optimizer = torch.optim.AdamW(model.parameters(), lr=1e-3)

for step in range(300):
    x, y = make_batch()
    logits = model(x)

    loss = criterion(
        logits.reshape(-1, logits.size(-1)),
        y.reshape(-1),
    )

    optimizer.zero_grad()
    loss.backward()
    optimizer.step()

    if step % 50 == 0:
        print(step, loss.item())
```

如果代码正常，loss 应该有下降趋势。

## 检查权重是否真的变化

训练前后比较一个参数：

```python
before = model.embed.weight.detach().clone()

x, y = make_batch()
logits = model(x)
loss = criterion(logits.reshape(-1, logits.size(-1)), y.reshape(-1))
optimizer.zero_grad()
loss.backward()
optimizer.step()

after = model.embed.weight.detach().clone()
print((after - before).abs().sum())
```

如果输出大于 0，说明权重确实变了。

如果是 0，要检查：

```text
有没有 backward
有没有 optimizer.step
参数 requires_grad 是否为 True
参数有没有传给 optimizer
loss 是否真的依赖这个参数
```

## 检查梯度

```python
for name, p in model.named_parameters():
    if p.grad is not None:
        print(name, p.grad.norm().item())
```

你要看的是：

- 梯度是不是全是 0。
- 梯度是不是特别大。
- 哪些层没有梯度。
- 梯度是否变成 NaN。

## 常见现象

### loss 不下降

可能原因：

- 学习率太大或太小。
- label 写错。
- logits 和 label 形状不匹配。
- 没有 `optimizer.step()`。
- 忘记 `model.train()`。
- 输入任务本身没有规律。

### loss 下降很快但泛化差

说明模型可能记住了数据。
玩具任务里这不一定是问题，但真实任务就要看验证集。

### loss 变成 NaN

通常先查：

```text
学习率
梯度爆炸
输入是否有异常值
loss 计算是否出现非法值
mask 是否把所有位置都遮住
```

## 这个实验学到了什么

你应该能把训练过程讲成：

```text
token id -> embedding -> Transformer -> logits -> loss -> backward -> step
```

更重要的是，你能亲眼看到：

```text
loss 是一个数字
梯度是每个参数上的张量
权重更新是 optimizer.step() 做的
```

这比只看概念扎实很多。
