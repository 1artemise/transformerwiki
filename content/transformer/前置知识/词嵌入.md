词嵌入（Word Embedding）
## 词嵌入是什么
简而言之就是把离散的词映射为连续稠密的向量，让计算机能理解词的含义,就像这样
```
“猫” → [0.2, -0.5, 0.8, 0.1, -0.3, ...]  (比如512维)
“狗” → [0.3, -0.4, 0.7, 0.2, -0.2, ...]  (相近)
“车” → [-0.8, 0.1, -0.2, 0.9, 0.4, ...] (不同)
```
当然，这个向量不是凭空得出的，而是经过了大量的文本训练，通过预测预测任务自动学习出来的。（最开始是随机生成，训练后就不是了）
### 为什么需要词嵌入
在词嵌入出现前，由于机器不能识别自然语言，人们往往使用One-hot编码来让机器认识词（也仅仅是认识）
```python
词典 = ["猫", "狗", "车", "苹果"]  # 4个词

“猫” → [1, 0, 0, 0]
“狗” → [0, 1, 0, 0]
“车” → [0, 0, 1, 0]
“苹果” → [0, 0, 0, 1]
```

| 问题       | 说明                       |
| -------- | ------------------------ |
| **维度灾难** | 词典10万词 → 10万维向量，每个词只有一个1 |
| **语义真空** | “猫”和“狗”的点积=0，完全看不出它们都是宠物 |
| **无法泛化** | 模型没见过“橘猫”，就不会把它和“猫”联系起来  |
是的，简而言之就是无法识别词与词之间的联系，比如猫狗应该是相近的，猫车应该是相远的。

## 词嵌入的思想是什么
 你认识一个词，就看它身边经常和哪些词一起出现。
 **直观例子**：
- "猫" 经常和 "抓"、"老鼠"、"可爱"、"宠物" 一起出现
- "狗" 经常和 "叫"、"看门"、"忠诚"、"宠物" 一起出现

**结论**：猫和狗的上下文相似 → 它们的词嵌入向量也应该相似。也就是说

词嵌入只做了一件事：**通过预测上下文的游戏，迫使模型把词语义压缩成向量，让相似词在向量空间中靠近。**

## 如何实现词嵌入

比如一句话 猫是宠物，有两种训练模型
### CBOW（连续词袋模型）快但糙

- **任务**：根据上下文预测中心词
- 输入：周围的词（如"是"、"宠物"）
- 输出：中心词（如"猫"）

### Skip-gram（跳字模型）慢但准
- **任务**：根据中心词预测周围的词
- 输入：中心词（如"猫"）
- 输出：周围的词（如"是"、"宠物"）
**两者本质相同**：通过预测任务，迫使模型学习有意义的向量。

当然，你不需要去重复造轮子，已经在gensim封装好了。
CBOW对应sg=0,Skip-gram对应sg=1。话不多说看代码！

```python
import jieba  
from gensim.models import Word2Vec

# 1. 准备原始句子 
sentences = [
   "我被猫追过",
    "我被猫咬过", 
    "但是我还是超级喜欢猫",
    "其实除了猫我还喜欢狗",
    "猫和狗都很可爱",
    
    "猫和狗都是人类的好朋友",
    "我想养一只猫和一只狗",
    "感觉猫猫干净一点",
    "狗有点狗味",
    "猫是宠物",
    "狗也是宠物",
]

#  2. 中文分词(原有的语料是句子，但是需要分割成每个词然后求每个词的向量)
tokenized_sentences = []
for sent in sentences:
    words = jieba.lcut(sent)  # 使用精确模式分词
    tokenized_sentences.append(words)

# 3. 训练模型 
model = Word2Vec(
    sentences=tokenized_sentences,  # 注意：传入的是分词后的列表！
    vector_size=200,#词向量纬度，越大越能捕捉复杂语义关系，但也需要更多数据和计算资源，一般100-300，越小训练越快但可能捕捉不到足够的语义信息
    window=5,#上下文窗口大小
    min_count=1,#忽略出现次数小于它的。用于过滤低频词
    sg=1,  # Skip-gram
    epochs=200,  # 增加训练轮数
    seed=42
)

# ========== 4. 验证结果 ==========
print(f"\n'猫'和'狗'的相似度: {model.wv.similarity('猫', '狗'):.4f}")

print("\n与'猫'最相似的词:")
for word, score in model.wv.most_similar('猫', topn=5):#返回相似度最高的五个词
    print(f"  {word}: {score:.4f}")

# 遍历所有词和它的向量
for word in model.wv.key_to_index:
    vector = model.wv[word]
    print(f"{word}: {vector[:5]}...")  # 只打印前5维这串代码过后我就知道了词向量和关系对吗
```
