让神经网络（多个神经元）可以从线性变为非线性
## 没有激活函数会怎样
```python
# 假设一个2层网络，没有激活函数
第1层输出 = W1 × X + b1#(一个神经元)
第2层输出 = W2 × (W1 × X + b1) + b2
         = (W2×W1) × X + (W2×b1 + b2)
         = W新 × X + b新  # 可以合并成一层！
# 结论：无论多少层，都能压缩成一层 → 白搭
```

## 激活函数怎么做的

在每一层的神经网络输出后都加上一层激活函数，让线性变为非线性

### 常见的激活函数

#### 1. Sigmoid函数

Sigmoid函数也叫Logistic函数，用于隐层神经元输出，取值范围为(0,1)，它可以将一个实数映射到(0,1)的区间，可以用来做二分类。在特征相差比较复杂或是相差不是特别大时效果比较好。sigmoid是一个十分常见的激活函数,简单但是有效。
