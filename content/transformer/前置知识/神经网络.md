## 什么是神经网络

由简单的神经元（处理单元）通过带权重的连接相互连接组成一个网络，来处理输入输出的映射关系，这就叫神经网络。一个神经元的组成如图。

## 一句话定义

**神经网络 = 网络结构（图） + 可学习的参数（权重） + 非线性激活函数**

## 神经网络有哪几类
| 类型              | 英文缩写      | 核心特征        | 适用场景       |
| --------------- | --------- | ----------- | ---------- |
| **前馈神经网络**      | FNN / MLP | 信息单向流动，无反馈  | 表格数据、分类、回归 |
| **卷积神经网络**      | CNN       | 局部连接 + 权重共享 | 图像、视频      |
| **循环神经网络**      | RNN       | 有循环连接，能处理序列 | 文本、时间序列    |
| [[Transformer]] | -         | 自注意力机制      | 长序列、大语言模型  |
| **生成对抗网络**      | GAN       | 生成器 + 判别器对抗 | 图像生成       |
前馈神经网络是最基础的一种神经网络，加上卷积是CNN，加上循环是RNN，加自注意力机制是Transformer

## 神经网络对比
| 特性         | 前馈(FNN) | 卷积(CNN) | 循环(RNN) | Transformer |
| ---------- | ------- | ------- | ------- | ----------- |
| **连接方式**   | 全连接     | 局部连接    | 循环连接    | 全连接+注意力     |
| **权重共享**   | ❌       | ✅       | ✅（时间步）  | ❌           |
| **处理变长输入** | ❌（需固定）  | ❌       | ✅       | ✅           |
| **位置信息**   | ❌       | ✅（局部）   | ✅（时序）   | 需加位置编码      |
| **并行能力**   | ✅       | ✅       | ❌       | ✅           |
| **参数效率**   | 低       | 高       | 中       | 中           |
| **代表模型**   | MLP     | ResNet  | LSTM    | BERT/GPT    |
解释一下：
#### 什么叫权重共享
在网络的每一个连接上都使用同一个权重，这就是权重共享。比如CNN卷积，就是一个3* 3的卷积核在整张图像上滑动，整张图共享一个权重。

#### 什么是变长输入
与之对应的是定长输入，也就是说输入的纬度/长度必须是固定的。
```python
# FNN（全连接层）输入必须是固定维度
fc = nn.Linear(784, 10)      # 固定输入784维
x1 = torch.randn(1, 784)     # ✅ 可以（28x28图片）
x2 = torch.randn(1, 1024)    # ❌ 不行（维度不对）
# FNN要求每个样本的特征数相同

# RNN / Transformer 可以处理不同长度的序列
text1 = "我好"           # 长度2
text2 = "今天天气真好"    # 长度6
# 两者可以放到同一个[[batch]]，通过padding对齐
```
为什么FNN不能处理变长输入，因为它的权重矩阵`W`的形状是固定的`[input_dim, output_dim]`。输入维度变了，矩阵乘法`X @ W`就做不了。

#### 并行能力
就是模型可以同一时间进行模型的多个计算任务，而不是做完一个才能做下一个。
这需要每个样本的计算不依赖其他样本的计算。
FNN等只需要计算矩阵乘法，GPU可以同时进行多个矩阵乘法。

#### 为什么CNN的参数效率最高
什么是参数效率？用**尽可能少的参数**达到**尽可能好的效果**。
CNN有什么特点？局部连接，权重共享，平移等变

|原因|说明|
|---|---|
|**局部连接**|每个神经元只连接局部区域（不是全局）|
|**权重共享**|同一卷积核在整个图像上复用|
|**平移等变**|模式出现在哪里都能识别，不需要重复学习|
