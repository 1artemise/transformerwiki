你需要先了解[损失函数](损失函数.md)（Loss Function）
## 梯度是什么？
我们知道模型需要在训练过程中不断调整权重，梯度就是调整的大小和方向
```
# 伪代码理解
梯度 = 损失函数对权重的导数
新权重 = 旧权重 - 学习率 × 梯度

# 梯度大 → 坡度陡 → 步子大
# 梯度小 → 坡度平 → 步子小

损失函数: 预测值与真实值的差距
如果梯度 = 5.0     → 说明很陡，参数要大调
如果梯度 = 0.001   → 说明很平，参数要微调
如果梯度 = None    → 说明平得跟死路一样
```

更完整的解释见 [[梯度与反向传播]]。
## 什么是梯度爆炸，发生在哪？

当梯度的大小非常大时，参数更新步子大得离谱，就炸了。
主要发生在**深层神经网络**（很多层的网络），特别是**循环神经网络（RNN）** 和**没有用残差连接（[Add](Add.md)）的深层网络**。

## 为什么会发生梯度爆炸

因为连乘效应，反向传播时，梯度从最后一层往前传，每经过一层都要×当层的权重。
权重一直大于1的时候乘积会一直叠

损失函数就变成 NaN（无穷大）
模型完全学不会

可以这样理解：

```text
梯度 = 1
经过一层 × 3 -> 3
再经过一层 × 3 -> 9
再经过一层 × 3 -> 27
...
```

层数越深，这个数可能变得越离谱。
一旦超过浮点数能稳定表示的范围，训练就会出现 `inf`、`NaN`。

## 梯度爆炸会导致什么

常见现象：

- loss 突然变得非常大。
- loss 直接变成 `NaN`。
- 参数里出现 `inf` 或 `NaN`。
- 生成结果突然崩掉。
- 梯度范数特别大。

这不是“模型正在努力学习”，而是权重更新已经失控。

## 怎么缓解

常用方法：

- 降低学习率。
- 使用梯度裁剪。
- 使用 [[LayerNorm]] 稳定数值分布。
- 使用 [[Add]] 让梯度有更稳定的路径。
- 检查输入数据是否有异常大值。
- 检查 loss 写法和 mask 是否正确。

梯度裁剪的意思是：如果梯度太大，就把它压到一个上限。

```python
torch.nn.utils.clip_grad_norm_(model.parameters(), max_norm=1.0)
```

这不是让模型变聪明，而是防止一次错误更新把模型炸掉。

## 梯度爆炸和学习率过大有什么区别

它们经常一起出现，但不是一回事。

```text
梯度爆炸：梯度本身已经很大
学习率过大：梯度不一定离谱，但更新步子太大
```

更新量由两者共同决定：

```text
更新量 = 学习率 × 梯度
```

所以训练不稳定时，要同时看学习率和梯度范数。
