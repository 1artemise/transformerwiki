
### 是什么？

梯度变得**极小**（比如 0.0000001），参数几乎不更新，模型停止学习。

先看 [[梯度与反向传播]] 会更好理解。

训练时权重更新大概是：

```text
新权重 = 旧权重 - 学习率 × 梯度
```

所以如果梯度接近 0，哪怕学习率正常，更新量也会非常小。
这时模型表面上还在训练，但很多层的权重几乎没变。

### 发生在哪？

也是**深层神经网络**，特别是**激活函数用Sigmoid或Tanh**的网络。

### 为什么会消失？

**原因：也是连乘效应，但这次乘的数很小**

```python
# 如果权重 < 1
第1层梯度 = 1.0
第2层梯度 = 1.0 × 0.3 = 0.3
第3层梯度 = 0.3 × 0.3 = 0.09
...
第10层梯度 = 1.0 × 0.3^9 = 0.000019  # 消失了！
```

还有一个重要原因：**Sigmoid [激活函数](激活函数.md)的导数最大只有0.25**

结果就是模型学不到新东西了。

## 为什么深层网络更容易遇到

反向传播是从后往前传梯度。

如果网络很深，梯度要经过很多层。
每经过一层，都要乘上一些导数或权重。

如果这些数长期小于 1：

```text
0.5 × 0.5 × 0.5 × 0.5 ...
```

结果会越来越小。

这就是为什么早期很深的网络不好训练：不是模型结构不能表达，而是前面层很难收到有效学习信号。

## 在 Transformer 里怎么缓解

Transformer 里有几个设计都在帮忙缓解这个问题：

- [[Add]]：残差连接给梯度一条更直接的路径，不必完全穿过复杂子层。
- [[LayerNorm]]：稳定每层输入输出的数值范围，减少梯度在层间乱飘。
- 合适的激活函数：比如 ReLU、GELU 比 sigmoid 更适合深层网络。
- 学习率 warmup：训练初期先小步走，避免一上来把参数推乱。

所以 Add 和 Norm 不是装饰，它们是深层 Transformer 能训起来的重要原因。

## 怎么判断可能梯度消失

常见表现：

- loss 长时间不下降。
- 前面层梯度范数非常小。
- 参数更新量几乎为 0。
- 深层模型表现还不如浅层模型。

如果是代码训练，可以打印每层梯度范数：

```python
for name, p in model.named_parameters():
    if p.grad is not None:
        print(name, p.grad.norm().item())
```

如果很多层梯度接近 0，就要怀疑梯度消失、学习率过小、参数被冻结或计算图断了。
