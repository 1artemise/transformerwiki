损失函数（Loss Function）
## 是什么
用于衡量模型的偏离程度的尺子。**损失值越小，模型预测越准，鲁棒性越好**
具体来说是，预测值f(x)与真实值Y的差异程度的运算函数，它是一个非负实值函数，通常使用L(Y, f(x))来表示

更直白一点：

```text
模型预测得越离谱，loss 越大
模型预测得越接近答案，loss 越小
```

如果没有损失函数，模型就不知道自己哪里错了，也就不知道权重该怎么改。

## **（重要）为什么使用损失函数？（提到了训练过程）**

损失函数使用主要是在模型的训练阶段，每个批次的训练数据送入模型后，通过前向传播输出预测值，然后损失函数会计算出预测值和真实值之间的差异值，也就是损失值。得到损失值之后，模型通过反向传播去更新各个参数，来降低真实值与预测值之间的损失，使得模型生成的预测值往真实值方向靠拢，从而达到学习的目的。

完整流程是：

```text
输入数据
  ↓
模型前向传播，得到预测
  ↓
损失函数比较预测和真实答案
  ↓
反向传播计算梯度
  ↓
优化器更新权重
```

所以 loss 本身不会自动改变模型。
真正改变权重的是后面的 [[梯度与反向传播]] 和优化器。

## 损失函数有哪些
讲两个常见的。
- 均方误差损失函数（用于回归问题）
![均方误差损失函数](../图/Pasted%20image%2020260508205935.png)
- 交叉熵损失函数（用于分类问题）
![交叉熵损失函数](../图/Pasted%20image%2020260508210042.png)

在 Transformer 这种语言模型里，最常见的是**交叉熵损失函数**。

比如模型在翻译时，下一个词真实答案是“猫”，但模型给出的概率是：

```text
猫：0.7
狗：0.2
车：0.1
```

那这次损失就比较小，因为正确答案“猫”的概率已经很高。

如果模型给成：

```text
猫：0.05
狗：0.8
车：0.15
```

损失就会变大，因为模型非常自信地猜错了。
所以训练语言模型时，本质就是不断让正确词的概率变高，让错误词的概率变低。

## 交叉熵为什么适合语言模型

语言模型每一步都在做一件事：

```text
从词表里选下一个 token
```

假设词表有 30000 个 token，模型会输出 30000 个分数。
这些分数经过 softmax 以后，变成 30000 个概率。

真实答案通常只有一个 token，比如答案是“猫”。
交叉熵关心的就是：

```text
模型给“猫”的概率有多高？
```

如果正确 token 的概率越高，loss 越小。
如果正确 token 的概率越低，loss 越大。

所以交叉熵很适合分类问题，也很适合语言模型的下一个 token 预测。

## loss 下降代表什么

loss 下降通常说明模型在训练集上越来越会预测答案。

但注意：

```text
训练 loss 下降，不一定代表模型真的泛化变好
```

如果训练 loss 下降，验证 loss 也下降，通常是好事。
如果训练 loss 继续下降，但验证 loss 上升，可能是过拟合。

这时就需要看 [[正则化]]、[[DropOut]]、数据质量和训练轮数。

## loss 不下降可能是什么原因

常见原因有：

- 学习率太大，权重一步改飞，loss 来回震荡。
- 学习率太小，权重每次几乎不动，loss 下降很慢。
- 梯度消失，前面层收不到有效更新信号。
- 梯度爆炸，loss 变成 `NaN` 或非常不稳定。
- 标签错位，比如本来要预测下一个 token，却把输入自己当成了答案。
- mask 写错，模型偷看未来或该看的位置被挡住。
- 模型太小，表达能力不够。
- 数据太少或噪声太大。

所以看到 loss 不动，不要只想“模型不行”。要顺着训练链路排查：

```text
数据 -> 标签 -> mask -> forward -> loss -> backward -> optimizer
```
