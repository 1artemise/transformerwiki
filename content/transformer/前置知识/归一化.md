归一化就是把一组数拉到比较稳定的范围里。
它解决的是一个很朴素的问题：**如果不同特征的数值差得太远，模型训练会很难。**

## 为什么数值范围很重要

假设一个样本有三个特征：

```text
年龄：25
年收入：500000
每天步数：8000
```

如果直接丢给模型，年收入这个数字太大，模型很容易把它当成最重要的东西。不是因为它真的最重要，而是因为它的数值量级太大。

这会导致两个问题：

- 梯度更新容易被大数值特征主导。
- 每一层输入分布变化很大，训练不稳定。

所以我们希望把这些数字变得更“同一个量级”。

## 常见的归一化方式

### 1. Min-Max 归一化

把数据压到 0 到 1 之间：

```text
x' = (x - min) / (max - min)
```

比如考试分数从 0 到 100，80 分归一化后就是 0.8。

这种方法简单直观，但很怕极端值。如果有一个特别离谱的最大值，其他数都会被挤在很小的范围里。

### 2. 标准化

让数据均值为 0，方差为 1：

```text
x' = (x - μ) / σ
```

这里的 `μ` 是均值，`σ` 是标准差。

标准化更常见于神经网络，因为它不要求数据一定落在 0 到 1，而是让数据围绕 0 稳定分布。

## BatchNorm 和 LayerNorm 的区别

这两个都是神经网络里的归一化层，但它们看的方向不同。

| 方法        | 看谁                    | 更常用在哪           |
| --------- | --------------------- | --------------- |
| BatchNorm | 一个 batch 里，同一个特征的不同样本 | CV              |
| LayerNorm | 一个样本里，所有特征            | NLP、Transformer |

## Transformer 为什么更常用 LayerNorm

因为语言任务里的句子长度不固定，batch 大小也可能变化。

BatchNorm 依赖一个 batch 的统计量，如果 batch 很小或者句子长短差异很大，它会不稳定。

LayerNorm 不看 batch，它只看当前这个 token 或当前这个样本内部的特征，所以训练和推理时行为更一致，也更适合 Transformer。

简单记：

```text
CV里常见 BatchNorm
Transformer里常见 LayerNorm
```
