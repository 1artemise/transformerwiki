softmax 是把一组数字变成一组概率的函数。

它最常出现在分类任务和注意力机制里。你可以先把它理解成一句话：

**softmax 会让大的数更大，小的数更小，最后所有数加起来等于 1。**

## 为什么需要 softmax

假设模型看完一句话后，觉得下一个词可能是：

```text
猫：3.0
狗：2.0
车：0.1
```

这些数字本身还不是概率，因为它们加起来不是 1，也不能直接解释成“模型有多相信”。

softmax 会把它们变成类似这样的结果：

```text
猫：0.70
狗：0.26
车：0.04
```

这样我们就可以说：模型认为下一个词最可能是“猫”。

## softmax 怎么算

公式长这样：

```text
softmax(x_i) = exp(x_i) / sum(exp(x_j))
```
![[Pasted image 20260509201253.png|617]]
看起来有点吓人，其实只做了两件事：

1. 先用 `exp` 把每个分数变成正数，而且分数越大放大得越明显。
2. 再除以所有 `exp` 的总和，让结果加起来等于 1。

比如：

```text
原始分数：[3, 2, 0.1]
exp之后：[20.09, 7.39, 1.11]
总和：28.59
softmax后：[0.70, 0.26, 0.04]
```

所以 softmax **不是简单地把数字缩放到 0 到 1**，而是会**突出相对更大的分数。**

## softmax 在 Transformer 里做什么

Transformer 里最核心的注意力公式是：

```text
Attention(Q, K, V) = softmax(QK^T / sqrt(d_k))V
```

你暂时不用急着理解全部符号，先抓住 softmax 的位置：

```text
QK^T 得到“相关性分数”
softmax 把分数变成“注意力权重”
权重再去加权 V
```

比如一句话是：

```text
我 喜欢 吃 苹果
```

当模型处理“吃”这个词时，它会算“吃”和其他词的相关性。假设分数是：

```text
我：0.2
喜欢：1.1
吃：0.8
苹果：2.5
```

softmax 后可能变成：

```text
我：0.06
喜欢：0.15
吃：0.11
苹果：0.68
```

这就表示：模型在理解“吃”时，最应该关注“苹果”。

## 为什么要除以 sqrt(d_k)

在注意力公式里还有一个 `/ sqrt(d_k)`，它是为了防止分数太大。

如果 `QK^T` 的数字特别大，softmax 会变得非常极端：

```text
[20, 1, 0] -> [几乎1, 几乎0, 几乎0]
```

这样梯度会很难更新，模型容易过早地“死盯”某个词。

除以 `sqrt(d_k)` 相当于先把分数压一压，让 softmax 不要太激动，训练会更稳定。
