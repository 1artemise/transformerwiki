位置编码（Positional Encoding）是 Transformer 用来补充词序信息的东西。
一句话理解：**Transformer 本身不按顺序读句子，所以我们要额外告诉它每个词在第几个位置。**

## 为什么需要位置编码

自注意力有一个很强的地方：每个词可以同时看整句话。
但这也带来一个问题：如果不加位置信息，它其实分不清下面两句话的顺序差异：
```text
猫 追 狗
狗 追 猫
```

词都是“猫、追、狗”，但意思完全相反。
RNN 是一个词一个词读，所以天然知道顺序。Transformer 一开始把所有词同时送进去，速度更快，但顺序感会丢掉。
所以我们需要位置编码告诉模型：

```text
猫在第1个位置
追在第2个位置
狗在第3个位置
```

## 位置编码加在哪里

Transformer 的输入不是只有词嵌入，而是：
```text
最终输入 = 词嵌入 + 位置编码
```
比如“猫”的词嵌入表示它的语义：
```text
猫是什么
```
位置编码表示它的位置：
```text
猫在第几个
```
两者加起来，模型拿到的就是：
```text
这个词是什么 + 这个词在哪里
```

## 论文里的正弦余弦位置编码

Attention Is All You Need 里使用的是固定的正弦、余弦函数：

```text
PE(pos, 2i) = sin(pos / 10000^(2i / d_model))
PE(pos, 2i+1) = cos(pos / 10000^(2i / d_model))
```

这个公式看着复杂，但它的目的很明确：
- `pos` 表示词的位置。
- `i` 表示向量里的第几维。
- 不同维度用不同频率的波表示位置。

你可以把它想成：每个位置都有一串独特的“位置指纹”。
## 为什么用 sin 和 cos
因为 sin 和 cos 有几个好处：
1. 每个位置都能生成一个确定的向量。
2. 近的位置编码相似，远的位置编码差异更大。
3. 模型可以通过这些波形关系学到相对位置，比如“前一个词”“后两个词”。
这点很适合语言，因为词和词之间的相对距离很重要。
比如：
```text
我 不 喜欢
我 喜欢 不
```

“不”离“喜欢”的位置不同，意思就可能完全不同。
## 固定位置编码和可学习位置编码
位置编码主要有两类：

| 类型      | 做法               | 特点           |
| ------- | ---------------- | ------------ |
| 固定位置编码  | 用 sin/cos 公式直接生成 | 不需要训练，论文原版使用 |
| 可学习位置编码 | 每个位置也当成参数训练      | 更灵活，很多后续模型使用 |

原始 Transformer 用固定位置编码，并不是说可学习位置编码不好，而是它希望模型能更容易推广到没见过的长度。

## 一句话总结

词嵌入告诉模型“这个词是什么意思”，位置编码告诉模型“这个词在什么位置”。

没有位置编码，Transformer 就像拿到一袋打乱顺序的词；有了位置编码，它才知道句子是按什么顺序组织起来的。
